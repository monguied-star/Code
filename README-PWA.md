# Mis Finanzas PWA

## Publicar
Sube juntos todos los archivos a un alojamiento HTTPS. Abrir index.html directamente desde Archivos no activa el modo PWA. Puedes usar GitHub Pages, Netlify, Vercel o Cloudflare Pages.

## Instalar en iPhone
1. Abre la dirección publicada en Safari.
2. Pulsa Compartir.
3. Pulsa Agregar a inicio.
4. Confirma Agregar.

Los datos se guardan localmente. Crea respaldos JSON periódicos.
